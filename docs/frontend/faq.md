## 登录一直转圈，或者页面上什么数据都加载不出来

先看 `.env.development` 里 `VUE_APP_BASE_API` 这一行配的端口，是不是和后端实际监听的端口一致。go-admin 后端默认端口是 `8000`，但项目里这份配置文件默认写的是 `8001`——如果没有手动改过，前端所有请求都会发到一个没有服务在监听的端口，界面上的表现就是转圈、白屏或者报网络错误，不会有明确的报错信息告诉你是端口配错了。详见[快速上手](/frontend)里的说明。

## `pnpm install` 或者 `pnpm dev` 报错

先确认本地环境版本：

```sh
$ node -v   # 需要 22 及以上
$ pnpm -v   # 需要 9 及以上
```

版本不够新是最常见的原因。

## 用代码生成器生成了新页面，但侧边栏里没有对应的菜单

这是正常现象，不是 bug。代码生成器只是把页面代码和菜单记录生成出来，**还需要手动去后台的角色管理里，给对应角色勾选这个新菜单和它的接口权限**，刷新页面才会出现在侧边栏。这一步哪怕是用超级管理员账号也不能跳过。具体操作看[配置角色权限](/intro/advanced/tutorial0450)，里面有实际截图。

## 忘记默认账号密码

用户名 `admin`，密码 `123456`。这是后端初始化数据里带的默认账号，生产环境部署前记得修改。
