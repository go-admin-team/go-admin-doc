## 不用手写页面

前面说过，go-admin-ui 的业务页面大多不是手写出来的。如果你要做一个全新的业务功能——比如"客户管理""合同管理"这类标准的"查询列表 + 新增/编辑 + 删除"页面，正常流程是：

1. 把这块业务需要保存的字段，设计成一张数据库表；
2. 用 go-admin 内置的代码生成器，指定这张表，一键生成对应的后端接口代码 **和** 前端页面代码；
3. 在后台的菜单管理里给这个新页面配置菜单和权限（参照[界面是怎么组织的](/frontend/jiegou)里讲的原理）；
4. 打开界面，新菜单出现，业务功能就能用了。

整个过程不需要写一行 Vue 或者 Go 代码——生成器按照项目里已经确定的写法产出代码，前后端两边风格是统一的。

## 生成器覆盖不了的部分

代码生成器解决的是标准的增删改查——字段怎么显示、怎么搜索、怎么保存，都是套用固定模板。如果你的需求超出了这个范围，比如某个字段要做特殊校验、某个按钮要触发一段自定义逻辑、页面样式要调整，生成器生成的代码就是你的起点，接下来怎么在这份代码基础上做修改，看下一篇[配合 AI 来改](/frontend/ai)。
